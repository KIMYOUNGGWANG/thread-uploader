## 1. 제품 개요

### 한 줄 요약
관심 주제별로 **24시간 안에 급상승한 쇼츠**를 모아 보여주고, 관리 중인 인플루언서 계정의 주제·톤에 맞춰 **벤치마킹 스크립트와 촬영컷**까지 뽑아주는, 에이전시용 숏폼 레퍼런스 도구.

### 해결하는 문제
- 에이전시 직원이 계정마다 매일 유튜브·인스타를 뒤져 "지금 터지는 영상"을 찾는 데 하루 1~2시간을 씀.
- 찾은 영상을 보고 "우리 계정 버전"으로 다시 기획하는 일이 사람 머릿속에서만 일어나서 품질이 담당자마다 다름.
- 계정이 10개를 넘어가면 한 사람이 못 따라감.

### 핵심 가치
- **급상승만 본다**: 누적 조회수가 아니라 "시간당 조회수 증가"로 줄을 세워서, 어제 터진 게 아니라 **지금** 터지는 걸 보여줌.
- **내 계정 버전으로 바로 변환**: 영상 자막을 뽑아 훅·구조·CTA를 분석하고, 등록해 둔 클라이언트 주제·톤·금지어를 섞어 스크립트와 컷 리스트를 생성.
- **다계정 전제**: 처음부터 "에이전시 1곳 → 클라이언트 N개" 구조. 경쟁 도구(Virlo, ViralDrop, 스니핏)는 대부분 1인 크리에이터용이거나 이미지 광고 중심.

## 2. 사용자

### 주요 사용자
- **누구**: 인플루언서 계정을 여러 개 대신 운영하는 에이전시·MCN·마케터 (직원 1~5명, 계정 5~100개)
- **상황**: 아침에 출근해서 오늘 찍을 콘텐츠 기획을 뽑을 때, 클라이언트 미팅 전에 레퍼런스를 준비할 때
- **목표**: 계정당 10분 안에 "오늘 벤치마킹할 영상 + 우리 버전 스크립트"를 손에 쥐기

### 부차 사용자 (Phase 2 이후)
- 1인 크리에이터 (클라이언트 1개짜리 개인 플랜)

### 사용자 시나리오
1. 에이전시 마케터가 아침에 숏폼레이더를 열고 "육아" 주제 탭을 본다
2. 24시간 내 국내외 급상승 쇼츠 카드가 증가속도 순으로 떠 있다. 하나를 고른다
3. "벤치마킹 생성" → 클라이언트 "@dragon.tiger_papa" 선택 → 10초 뒤 훅 분석 + 우리 버전 스크립트 + 촬영컷 6개가 나온다
4. 복사해서 촬영팀에 보낸다. 다음 클라이언트로 넘어간다

## 4. 사용자 흐름 (User Flow)

### 핵심 흐름
```
로그인 -> 주제 탭 선택 -> 급상승 카드 둘러보기 -> 영상 선택 -> 클라이언트 선택 -> 생성 -> 복사
```

### 상세 흐름
1. **로그인**: 구글/카카오 → 첫 로그인이면 Organization + Free 플랜 자동 생성 → 온보딩에서 클라이언트 1개 등록 유도
2. **피드**: 상단 주제 탭(육아·부동산·건강·리빙·음식·뷰티·재테크·에듀·동기부여…) + 국내/해외 토글 + "24h / 48h" 토글. 카드: 섬네일(세로) · 조회수 · "N시간 전" · 채널 · 좋아요/댓글 · 증가속도 배지
3. **영상 상세**: 유튜브 임베드 플레이어 + 스냅샷 그래프(조회수 추이) + 자막 미리보기 + "벤치마킹 생성" 버튼
4. **생성**: 클라이언트 드롭다운 → 생성 → 결과 3블록: ① 원본 분석(훅 유형·구조·CTA·왜 터졌나) ② 우리 버전 스크립트(훅/본문/CTA, 15~45초 기준) ③ 촬영컷 리스트(컷 번호·장면·대사·자막·길이)
5. **복사/저장**: 마크다운 복사, 생성 이력에 자동 저장
6. **결제**: 생성 횟수 소진 시 업그레이드 모달 → 토스 정기결제 → 즉시 한도 상향

## 5. 성공 기준

- [ ] 피드가 매시간 갱신되고, 각 주제 탭에 24h 내 영상이 최소 20개 이상 항상 떠 있다
- [ ] 유튜브 API 일일 쿼터(10,000 유닛) 안에서 10개 주제 × 50개 시드 채널을 운영한다
- [ ] 벤치마킹 생성이 15초 안에 끝나고, 결과에 스크립트·촬영컷이 모두 포함된다
- [ ] 출시 4주 안에 유료 전환 에이전시 3곳 (Pro 이상)
- [ ] 에이전시 1곳이 클라이언트 10개를 등록하고 주 20회 이상 생성한다 (활성 기준)

## 6. 안 만드는 것 (Out of Scope)

> 이 목록에 있는 건 Phase 1에서 만들지 않습니다.
> AI에게 코드를 시킬 때 이 목록을 함께 공유하세요.

- 인스타그램·틱톡 수집 -- 이유: 공식 API가 없어 스크래핑 비용·차단 리스크가 큼. 유튜브로 수요 검증 후 Phase 2
- 영상 다운로드·재편집 -- 이유: YouTube API 약관 위반. 임베드 플레이어만 사용
- 영상 자동 업로드·예약 발행 -- 이유: 별개 제품. 기획 단계까지만 담당
- 팀원 초대·권한 -- 이유: 초기 고객은 1~2인 운영. Phase 3
- 커스텀 주제·저장 보드 -- 이유: 기본 주제로 충분한지 먼저 확인. Phase 2
- 모바일 앱 -- 이유: 사무실 데스크톱 작업. 반응형 웹으로 충분
- 영어권 UI -- 이유: 국내 에이전시 먼저
