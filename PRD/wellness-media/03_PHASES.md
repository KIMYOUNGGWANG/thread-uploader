## Phase 1: MVP — 끝까지 도는 파이프라인 (1~2주, 추측)

### 목표
매일 아침 10분 검수만으로 인스타 캐러셀과 스레드에 웰니스 × 비즈니스 콘텐츠가 자동으로 올라간다.

### 기능
- [ ] 웰니스 미디어 제품 프로필(Brand) 생성 + 포지셔닝·톤·금지 표현 사전 설정
- [ ] 출처 등록 화면 + RSS 매일 수집 크론 + 링크 수동 추가
- [ ] AI 글감 점수화 → 오늘의 후보 리스트
- [ ] AI 초안: 인스타 캡션 + 스레드 글 + 카드 7~10장 텍스트
- [ ] 카드 이미지 렌더 (매거진 톤 템플릿 2~3종)
- [ ] 금지 표현 자동 하이라이트 + 대체 표현 제안
- [ ] 검수 대시보드: 카드 미리보기·수정·승인·반려·예약 시간
- [ ] 스레드 예약 게시 (기존 크론)
- [ ] 인스타 캐러셀 예약 게시 (Meta 권한 승인 전엔 이미지 ZIP 다운로드)
- [ ] 성과 수집 (게시 24시간·72시간 후)

### 데이터
- ContentSource, SourceArticle, PostArticle, PostSlide (신규)
- Brand, Post, Publication, ChannelUpload (기존)

### 인증
- 기존 운영자 로그인(`src/lib/auth.ts`) 그대로

### "진짜 제품" 체크리스트
- [ ] 실제 DB 연결 (목업 데이터 X)
- [ ] 실제 인증 (하드코딩된 비밀번호 X)
- [ ] 실제 서버에 배포 (Vercel, localhost X)
- [ ] 실제 인스타·스레드 계정에 1건 이상 자동 게시됨

### Phase 1 시작 프롬프트
```

- 검수 대시보드 + 인스타·스레드 예약 게시 + 성과 수집

반드시 지켜야 할 것:
```

## Phase 2: 확장 — 숫자로 똑똑해지기 (1~2주, 추측)

### 전제 조건
- Phase 1이 2주 이상 안정적으로 게시 중

### 목표
어떤 포맷·주제가 터지는지 숫자로 보고, 다음 글감 선택에 자동 반영한다.

### 기능
- [ ] 포맷·주제별 성과 리포트 (저장·공유 중심)
- [ ] 성과 → 글감 점수 보정 (기존 학습 루프 연결)
- [ ] 웹 출처 추가 + 중복 주제 감지 (같은 이슈 반복 방지)
- [ ] 템플릿 변주 + AI 배경 이미지
- [ ] 해시태그·에디터 서명 관리

### 추가 데이터
- 필요 시 성과 집계용 뷰만 추가

### 통합 테스트
- Phase 1 수집·초안·게시가 그대로 도는지 확인

## Phase 3: 고도화 — 플라이휠 (기간 미정)

### 전제 조건
- Phase 1 + 2가 안정적으로 운영 중이고 팔로워가 쌓이기 시작함

### 목표
미디어로 모은 사람을 매출로 연결한다.

### 기능
- [ ] 댓글 키워드 → 리드마그넷 자동 발송
- [ ] AI 루틴 도구 1회 결제 페이지
- [ ] 커머스 제휴 링크 관리 (일반식품·용품만)
- [ ] B2B: 여러 계정(워크스페이스) 지원

### 주의사항
- 결제 로직은 착수 전에 반대 검토 + 승인 필요
- 인스타 DM 자동 발송은 Meta 메시징 정책 확인 필요
- 건강기능식품은 판매업 신고·광고 사전심의 대상이라 커머스에 넣지 않는다
