> 생성일: 2026-11-10
> 생성 도구: Show Me The PRD

## 1. 제품 개요

### 한 줄 요약
웰니스 × 비즈니스 뉴스를 매일 모아 AI가 카드뉴스와 스레드 글로 만들고, 운영자는 하루 10분 검수만 하면 인스타·스레드에 자동으로 올라가는 1인 미디어 운영 시스템.

### 해결하는 문제
- 벤치마크 계정 @wellness_highlight는 47일 동안 156개를 올렸다(하루 3.3개, 2026-11-09 수집). 이 정도 물량을 1인이 손으로 리서치·작성·디자인·업로드하면 다른 일을 못 한다.
- 손으로 하면 "어떤 주제가 터지는지"를 감으로만 판단하게 된다.
- 건강 정보라서 질병·효능 단정 표현을 쓰면 광고 규제(식품표시광고법, 건강기능식품법) 위험이 있는데, 1인이 매번 걸러내기 어렵다.

### 핵심 가치
- **포지셔닝**: 웰니스 × 비즈니스. 셀럽·브랜드가 웰니스로 돈 버는 이야기와 트렌드 리스트에 집중한다. 벤치마크에서 반응 상위였던 주제다(헤일리 비버 립밤 케이스 좋아요 4,290, 2027 소비 트렌드 3,573, 에레혼 1,771).
- **반응이 약한 포맷은 처음부터 뺀다**: 위클리 뉴스 요약(43), 해외 브랜드 단신(50~60), 릴스(41~112).
- **이미 있는 엔진을 재사용한다**: Portfolio Growth OS의 AI 생성, 스레드 게시, 성과 수집, 인스타 연동, 카드 렌더러를 그대로 쓴다.
- **플라이휠의 입구다**: 이 미디어가 모은 사람이 나중에 AI 루틴 도구(1회 결제), 일반식품 키트, 웰니스 사업자용 B2B 툴(Phase 3)로 이어진다.

## 2. 사용자

### 주요 사용자
- **누구**: 운영자 1명(본인). 콘텐츠 독자는 2030 웰니스·자기계발 관심층과 웰니스 창업자·마케터.
- **상황**: 아침에 폰으로 대시보드를 열어 오늘 올라갈 초안을 검수한다.
- **목표**: 하루 10분 안에 인스타 1~2개, 스레드 1~2개를 품질 걱정 없이 내보낸다.

### 사용자 시나리오
1. 새벽 크론이 RSS 출처에서 웰니스 기사를 모으고, AI가 점수를 매겨 "오늘의 글감 후보"를 만든다.
2. 상위 글감이 자동으로 초안이 된다: 인스타 캡션, 스레드 글, 카드 7~10장.
3. 운영자가 아침에 대시보드를 열어 카드 미리보기를 보고, 빨간 줄(금지 표현)을 고친 뒤 승인한다.
4. 예약 시간에 인스타 캐러셀과 스레드에 올라간다.
5. 24시간 후와 72시간 후 성과가 수집된다.

## 4. 사용자 흐름 (User Flow)

### 핵심 흐름
```
RSS 수집 → 글감 점수화 → AI 초안 + 카드 렌더 → 금지 표현 검사 → 운영자 검수·승인 → 예약 게시(인스타·스레드) → 성과 수집
```

### 상세 흐름
1. **수집 (새벽 크론)**: 활성 출처를 돌며 새 기사만 저장한다. URL 기준으로 중복을 막는다.
2. **점수화**: 기사마다 포지셔닝 적합도와 포맷 후보(트렌드 리스트 / 셀럽×사업 / 마인드셋)를 매긴다.
3. **초안 생성**: 상위 N개(기본 2개)를 초안으로 만든다. 카드 이미지까지 렌더한다.
4. **검사**: 금지 표현 사전과 AI 검사로 걸린 문장을 표시한다. 걸린 게 있으면 승인 버튼 옆에 경고를 띄운다.
5. **검수**: 운영자가 텍스트를 고치면 카드를 다시 렌더한다. 승인하면 예약 시간이 확정된다.
6. **게시**: 스레드는 기존 크론으로, 인스타는 캐러셀 API로 올린다. 실패하면 재시도하고 대시보드에 표시한다.
7. **성과**: 24시간·72시간 스냅샷을 저장한다.

---

## 5. 성공 기준

- [ ] 운영자의 하루 검수 시간이 10분 이하다 (초안 2개 기준, 직접 재봄)
- [ ] 2주 연속으로 하루 인스타 1개 이상, 스레드 1개 이상이 사람 손 업로드 없이 게시된다
- [ ] 게시물 중 금지 표현이 그대로 나간 건이 0건이다 (주 1회 샘플 점검)
- [ ] 첫 30개 게시물의 저장 수 중앙값을 기록해 다음 달 목표의 기준선으로 삼는다

## 6. 안 만드는 것 (Out of Scope)

> 이 목록에 있는 건 Phase 1에서 만들지 않습니다.

- 릴스·영상 자동 제작 -- 이유: 벤치마크에서 릴스 반응이 가장 낮았고, 영상 공장은 다른 제품에서 이미 운영 중이다
- 위클리 뉴스 TOP 10 요약 포맷 -- 이유: 벤치마크 반응 최하위(좋아요 43)
- 웹 스크래핑 출처 -- 이유: RSS와 수동 링크로 시작하고 Phase 2에서 추가한다
- 구독형 루틴 웹앱 -- 이유: 사용자가 원하지 않는다
- 결제·커머스 -- 이유: Phase 3 플라이휠 단계에서 다룬다
- 여러 운영자·여러 고객사(멀티 테넌트) -- 이유: B2B 툴은 Phase 3
