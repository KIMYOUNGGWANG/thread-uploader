# 영상 레퍼런스 통합 문서

2026-10-29. 흩어져 있던 숏폼 영상 레퍼런스(세션 8개, 파일 7개, 유튜브 자막)를 한 곳에 모았다. 앞으로 **영상 품질 기준의 단일 출처**는 이 문서다.
영상 작업을 시작할 때 이 문서를 먼저 읽는다. 기준이 바뀌면 이 문서를 먼저 고치고, 템플릿과 검사 코드가 따라간다.

읽는 법: 표의 `R1`~`R17`은 아래 "레퍼런스 목록"의 번호다. **미확인**은 확인하지 못했다는 뜻이다. 영상 속 숫자(비용 등)는 제작자의 주장이라 우리가 검증한 값이 아니다.

---

## 품질 기준

레퍼런스 여러 개에서 공통으로 나온 것만 뽑았다. 영상 1편이 이 12개를 지키는지가 "평균 이상 광고 영상"의 기준이다.

| # | 기준 | 확인 방법 | 근거 |
|---|---|---|---|
| Q1 | **첫 프레임부터 글자가 보이고, 첫 1초에 "나한테 하는 말" 훅이 나온다.** 훅은 예언이 아니라 행동 문장으로 쓴다 ("11월엔 ~ 하나만 해") | 0초 프레임 캡처에 훅 글자가 있다 | R7, R10, R4, PRD 5장 |
| Q2 | **정지형(6~10초)은 처음부터 전부 보인다.** 짧아서 반복 재생되고, 마지막 프레임 = 첫 프레임이라 끊김이 없다 | 0초 프레임에 모든 항목이 있다 / 첫·끝 프레임 비교 | R7, R8, R14 |
| Q3 | **움직임 없는 구간이 없다.** 정지형도 글자만 고정이고 배경·요소는 계속 움직인다. "슬라이드 말고 영상처럼" | 구간별 프레임을 뽑아 서로 달라졌는지 비교 | R1, R2(bang-motion), R14, R17 |
| Q4 | **안전 영역**: 화면 위 15%·아래 25%에는 핵심 글자를 두지 않는다. 오른쪽 버튼 자리도 피한다 | 렌더 프레임에 안전 영역 띠를 겹쳐 본다 | R14, R11, R17 |
| Q5 | **소리가 있다.** 무음은 넘김 1순위. BGM 한 곡을 같은 포맷에서 공유하고, 말·효과음보다 작게 숫자로 정한다(예: 말 음량의 10%). 폰 스피커로 들어도 들려야 하고, 가사 있는 곡은 쓰지 않는다 | 소리 있음 + 음량 수치가 설정에 적혀 있다 | R14, R4, R11, R1, R15 |
| Q6 | **스타일은 브랜드당 한 번 고정한다** (색·글꼴·로고·배경 재질). 안 정하면 결과가 "빛 입자 + 우주"로 몰리고, "내 브랜드로"라고만 하면 색이 틀린다 | 브랜드 설정 파일 하나에서 색·글꼴을 읽는다 | R1, R4, R14 |
| Q6-1 | **cosmicpath 스타일 (2026-10-29 사용자 결정)**: 0~1.7초 사진·실사 훅 → 흑요석(`#0a0908`)·샴페인 골드(`#c8a84d`/`#f5d77f`) 키네틱 본문. 본문 글자는 Pretendard 900, 한자만 명조. 사주 느낌은 한자 한 글자와 훅 사진(먹·붓·나무 탁자)이 낸다. 샘플 A(수묵 한지)·B(키네틱)·C(사진 훅+한지) 중 "C의 훅 + B의 본문"으로 정했다 | 템플릿 `kinetic-list`가 이 색·글꼴만 쓴다 | 1a 스타일 샘플 |
| Q7 | **글자 규칙**: 글자마다 역할(계속 떠 있음 / 잠깐 강조)을 먼저 정한다. 자막은 영상 하나에 한 가지 스타일. 순간 강조는 30초에 2~3개까지. 글자 대비는 WCAG AA | HyperFrames `check`가 대비를 잡는다 | R11, R17 |
| Q8 | **글자 잘림·겹침·빈 화면이 없다.** 아래쪽 1/3이 비면 안 된다. 검은 화면은 0.3초 이하. "다 됐다"는 말을 믿지 않고 **렌더된 프레임을 직접 본다** | 프레임 캡처 자동 검사 + (선택) 화면만 보고 평가하는 비평 단계 | R1, R11, R17, R14, PRD 5장 |
| Q9 | **길이**: 정지형 6~10초, 카드 선택형 16초, 설명형 15~30초. 광고형은 20초 안팎까지 | 렌더된 mp4 길이가 포맷 범위 안이다 | PRD 5장, R7, R5, R12 |
| Q10 | **전체 렌더 전에 정지 프레임 몇 장(스토리보드)을 먼저 본다.** 고치는 비용이 훨씬 작다. AI 영상은 저해상도 초안부터 | 샘플 2~3장을 보고 사용자가 고른 뒤 렌더한다 | R4, R5, R11 |
| Q11 | **한 번에 하나만 바꿔서 비교한다.** 훅만 다르게, 포맷만 다르게. 차이가 2배 이하면 운과 구분이 안 된다 | 장부에 바꾼 것 한 줄만 적혀 있다 | R17, R15 |
| Q12 | **로고와 한글은 코드로 쓴 실제 글자를 쓴다.** AI가 한글·로고를 그리면 자세히 볼 때 깨진다 | 글자가 HTML 텍스트·원본 파일에서 나온다 | R5 |

충돌했던 것과 정리:

| 충돌 | 정리 |
|---|---|
| 하단 안전 영역: 비주얼 방향 1단계 문서는 18%, 촬영 컷 구성표와 PRD는 25% | 25% 채택 (더 넓고 최신) |
| 음악: 실험 문서는 "음악 없음 또는 전 편 동일", 비주얼 방향은 BGM −18dB | "전 편 동일 BGM"으로 둘 다 만족 (Q5) |
| "정지형"인데 "움직임 없는 구간 금지" | 글자는 고정, 배경·요소는 움직임 (Q3) |

근거가 약한 부분: 경쟁 릴스(R7)는 **캡션·길이·조회수만 봤고 영상 자체는 보지 않았다** (`reels-shot-list.md`에 적힌 그대로). Q1~Q2의 "상위는 이렇게 생겼다"는 실제 영상을 보고 확인한 값이 아니다. 영상으로 확인하려면 `watch` 스킬로 상위 영상을 열어 이 문서를 고친다.

## 확인 못 한 것

- 경쟁 릴스(R7) 영상 자체를 본 적이 없다. Q1~Q3의 "상위는 이렇게 생겼다"는 캡션·길이·조회수에서 나온 추정이다.
- HyperFrames 공식 X 글의 원문 주소와 정확한 문구. R4 기사가 인용한 내용만 확인했다.
- R4 기사의 정확한 게시일, R5 영상의 게시일.
- 도구 라이선스: 위 표에서 **미확인**으로 적은 모든 줄. 쓰기 전에 저장소 LICENSE를 직접 확인한다.
- 무료 TTS 엔진, 무료 BGM 생성 품질(ACE-Step 포함), cosmicpath 브랜드 스타일 1개 (PRD 9장의 열린 질문).
