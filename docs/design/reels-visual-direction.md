# 릴스 템플릿 비주얼 방향 (ig_rank_10s, ig_pickcard_16s)

2026-10-23. 첫 렌더가 "단색 배경 + 글자만 뜨는 슬라이드"라 올릴 수준이 아니라는 판정을 받고 쓴 글이야. 템플릿을 고치기 전에 방향을 먼저 적어둬. 화면이 이상하면 이 문서를 먼저 고치고 템플릿을 따라가게 해.

## 문제 (2026-10-22 렌더 기준)

- 배경이 단색 검정이고 움직임이 글자 등장뿐이라 영상이 아니라 슬라이드로 보여.
- 소리가 없어. 릴스에서 무음은 넘김 1순위야.
- 화면 아래 절반이 비어 있어. 인스타 UI가 가려도 너무 비어.
- 카드 선택의 A/B/C가 카드가 아니라 네모 박스야. "뒤집어 보는 맛"이 없어.
- 브랜드 요소가 없어. 로고·색·폰트 어느 것도 CosmicPath 티가 안 나.

## 방향

경쟁 상위 릴스(soaring_tarot 카드 선택, zendi_tarot 랭킹)가 먹히는 건 문구가 아니라 분위기야. "밤하늘·우주·빛"으로 통일하고, 글자는 그 위에 얹는 구조로 바꿔.

### 1단계 (이번)

| 항목 | 결정 |
|---|---|
| 배경 | 느리게 흐르는 성운·별 영상 1개를 두 템플릿이 공유. 5초 클립을 앞뒤로 반복(핑퐁)해서 끊김 없이 늘려. 위에 검정 40% 그라데이션을 깔아 글자 대비를 확보해. |
| 음악 | 잔잔한 앰비언트 1곡, −18dB. 두 템플릿 공유. 랭킹은 항목 등장마다 짧은 효과음 없이 음악만. |
| 하단 | 브랜드 마크 "CosmicPath" + 서브 카피 한 줄("내 일간 모르면 → 프로필 링크 1분"). 인스타 캡션 영역(하단 18%) 위에 걸치게. |
| 오행 색 | 랭킹 항목의 일간 첫 글자로 색을 정해. 갑·을=목 `#4ade80`, 병·정=화 `#fb7185`, 무·기=토 `#fbbf24`, 경·신=금 `#e2e8f0`, 임·계=수 `#60a5fa`. 숫자와 테두리에 쓰고 본문 글자는 흰색 유지. |
| 제목 | 크기 유지하되 아래에 얇은 강조선. 색은 흰색, 그림자로 배경과 분리. |

### 2단계 (다음)

- 카드 선택: 타로풍 카드 일러스트 3장, 뒷면→앞면 뒤집기. 이미지 생성 필요.
- 경쟁 릴스 레퍼런스 2~3개를 받아 톤 재조정.
