# 실험: 사주 릴스 포맷 — 랭킹 정지 vs 카드 선택 (cosmicpath)

사전 등록 문서야. 첫 릴스를 올린 뒤에는 아래 가설, 지표, 편수, 판정 기준을 바꾸지 않아.

목적은 Threads 개선이 아니라 **인스타 릴스라는 새 유입 채널을 장부로 관리하는 것**이야. Threads 글 조회수 중앙값은 123이라 비교 기준으로 쓰기엔 너무 낮아. 릴스는 기준점이 없으니 이 실험이 첫 기준점이 돼.

## 가설

- H1: 카드 선택(16초) 릴스는 랭킹 정지(10초) 릴스보다 **1,000뷰당 저장 수**가 높다. (saveable, self-classification 모드가 작동한다는 뜻)
- H2: 랭킹 정지 릴스는 카드 선택보다 **조회수 중앙값**이 높다. (friend share 모드로 퍼진다는 뜻)

둘 다 맞으면 역할을 나눠(랭킹=유입, 카드=저장·전환). 둘 다 틀리면 pause 규칙으로 가.

## 설계

- **브랜드:** cosmicpath 인스타 계정 1개. 업로드는 수동이야(릴스 게시 API 경로 없음).
- **포맷 2종 (플레이북 모드 매핑):**
  - `ig_rank_10s` 랭킹 정지 이미지 10초 → friend share, saveable. 예: "2027년 운 좋은 일간 TOP 5"
  - `ig_pickcard_16s` 카드 선택 16초 → self-classification. 예: "A/B/C 중 끌리는 카드 하나, 당신의 11월"
- **CTA (공통, 선택형만):** "저장해 두고 A/B/C 중 하나 골라 댓글". 맛보기 리포트는 프로필 링크 → 랜딩으로만 연결해. 키워드 DM, 자동 답글, "댓글 달면 해석" 금지.
- **배정:** 번갈아 올려(R, C, R, C …). 주 2편씩, 포맷당 6편, 총 12편, 약 6주. 같은 주에 두 포맷이 하나씩 들어가게 해서 시기 효과를 나눠.
- **고정 조건:** 업로드 요일·시간대, 캡션 길이(80자 이하), 해시태그 3개, 음악 없음(또는 전 편 동일). 바꾸는 건 포맷뿐이야.
- **중간 확인 금지:** 12편이 다 올라가고 마지막 편이 7일 지나기 전에는 판정하지 않아. 단, 아래 "조기 중단" 조건은 예외야.
- **조기 중단:** 계정 제한 경고가 한 번이라도 뜨면 즉시 멈추고 이 문서에 기록해. 계정이 유일한 유입 채널이야.

## 측정

편당 업로드 7일 뒤에 인스타 인사이트에서 읽어 아래 장부에 적어. 열은 `TikTokVideoMetric`(views, saves, profileClicks, landingClicks, conversions)과 같게 맞춰서, 나중에 템플릿이 생기면 DB로 옮길 수 있게 해.

- **1차 지표(H1):** saves / views × 1,000
- **1차 지표(H2):** views 중앙값
- **참고 지표:** profileClicks, landingClicks, 결제창 진입(conversions). 참고용이야. 12편으로는 신호가 안 나올 가능성이 커서 판정에는 안 써.
- **노이즈 기준점:** Threads에서 같은 글을 두 번 올린 18쌍의 조회수 차이 중앙값이 1.42배였어(`2026-10-16-post-length.md`). 릴스도 포맷당 6편이면 **2배 이하 차이는 운과 구분이 안 돼**. 그래서 판정 기준을 2배로 둬.

## 판정 (플레이북 Decision rules를 포맷별로 적용)

마지막 편 7일 뒤, 포맷별로 하나씩 판정해.

- **Double down:** 그 포맷의 저장률 또는 조회수 중앙값이 다른 포맷의 2배 이상이고, 댓글이 대부분 A/B/C 같은 짧은 선택이야. → 다음 6주는 그 포맷 비중을 2:1로.
- **Revise format:** 조회수는 나오는데 저장·프로필 클릭이 안 움직여. 또는 댓글이 긴 상담 요청으로 바뀌어. → 훅이나 카드 구성을 바꾸고 같은 포맷으로 6편 더.
- **Revise offer:** 저장은 되는데 랜딩 클릭·결제창이 0이야. → 포맷은 두고 프로필 링크 문구와 랜딩 첫 화면을 바꿔.
- **Pause:** 12편 뒤에도 두 포맷 모두 저장·프로필 클릭·랜딩 클릭이 사실상 0이거나, 먹히는 건 예측형·"댓글 달면 해석" 뿐이야. → 릴스 채널 보류, Threads로 복귀.
- **판정 불가:** 두 포맷 차이가 2배 미만 → "효과 확인 못 함"으로 기록하고, 다음 가설(시즌 훅 또는 일간별 체인)로 넘어가.

## 보류한 것 (이 실험 범위 아님)

- **DB 주입:** `ManualViralExample`에 포맷·길이·배수 칸이 없고 `buildManualCandidate`가 `rawMetrics`를 `{ imported: true }`로 고정해. 릴스 18편으로는 분석 가치가 없어서 템플릿이 생기고 우리 릴스 숫자가 쌓인 뒤에 붙여.
- **포맷 ID `ig_rank_10s`, `ig_pickcard_16s` 코드 등록:** `tiktok-draft-service.ts`의 formatId는 Remotion 템플릿과 한 몸이라 템플릿(3단계)과 같이 추가해. 그 전까지 이 문서의 ID는 장부용 라벨이야.
- **분류 어휘:** `viral-llm-analysis.ts`의 `structureType`에 랭킹 정지, 카드 선택, 말하는 영상, 일간별 체인, 시즌 훅, 상담 유도 6종은 추가했어. Threads 수집 글을 사주 포맷으로 태깅하기 위한 거고, 이 실험 판정에는 쓰지 않아.
- **주 1회 경쟁 계정 스캔:** Aside가 외부에서 소량 읽어 JSON으로 넘기는 방식을 유지해. 앱에 크롤러를 넣지 않아.
